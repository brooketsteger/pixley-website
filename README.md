# Pixley Website

Marketing site for [usepixley.com](https://usepixley.com). Built with Next.js 14 (App Router), TypeScript, and Tailwind. Replaces the previous Figma Sites version.

## Stack

- **Next.js 14** (App Router, server components by default)
- **TypeScript**
- **Tailwind CSS** with the Pixley brand palette wired into `tailwind.config.ts`
- **Poppins** via `next/font/google` (matches the app's typography)
- **Supabase** client placeholder in `lib/supabase.ts` for future auth/data
- Deployed on **Vercel**, DNS at **GoDaddy**

## Local development

```bash
npm install
cp .env.example .env.local   # fill in Supabase keys when ready
npm run dev
```

Open http://localhost:3000.

## Project structure

```
app/
  layout.tsx          # root layout, fonts, JSON-LD structured data
  page.tsx            # home (hero + features + tagline)
  contact/page.tsx
  privacypolicy/page.tsx
  tos/page.tsx
  sitemap.ts          # auto-generated /sitemap.xml
  robots.ts           # auto-generated /robots.txt (allows AI crawlers)
  globals.css
components/
  Header.tsx
  Footer.tsx
  LegalLayout.tsx
lib/
  supabase.ts         # client placeholder
public/               # logo, hero image, OG image (drop assets here)
```

## SEO + AEO

- Per-page `<title>` and `description` via Next.js `Metadata` API
- OpenGraph + Twitter card tags in root layout
- JSON-LD `Organization` and `MobileApplication` schema
- `sitemap.xml` and `robots.txt` generated by Next.js
- AI crawler user agents (GPTBot, PerplexityBot, ClaudeBot, Google-Extended, Applebot-Extended) explicitly allowed for Answer Engine Optimization

## Deploy

1. Create empty repo `pixley-website` on github.com under the `brooketsteger` account.
2. From the `website/` folder:
   ```bash
   git init
   git add .
   git commit -m "Initial Pixley website"
   git branch -M main
   git remote add origin https://github.com/brooketsteger/pixley-website.git
   git push -u origin main
   ```
3. In Vercel: New Project → import `brooketsteger/pixley-website` → deploy. Vercel auto-detects Next.js.
4. Vercel gives you a `*.vercel.app` preview URL. Review against current usepixley.com.
5. When ready to cut over, in GoDaddy DNS:
   - **A** `@` → `76.76.21.21`
   - **CNAME** `www` → `cname.vercel-dns.com`
   - Add `usepixley.com` and `www.usepixley.com` as domains in Vercel project settings.
